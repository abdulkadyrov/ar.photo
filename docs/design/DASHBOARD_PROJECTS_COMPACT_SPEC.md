# Компактные мобильные экраны: Главная и Проекты

## Цель

На экране шириной 319–390 px пользователь должен сразу видеть полезные данные и первые рабочие объекты. Шапка, hero-блок и фильтры не должны занимать большую часть первого экрана.

Редизайн меняет только представление. Репозитории каталога, React Query-ключи, параметры URL, создание и изменение проектов, статусы, черновики, архив, корзина, пагинация и права доступа остаются без изменений.

## Главная

### Первый экран

- компактная шапка с заголовком, короткой кнопкой создания и выходом;
- account eyebrow и длинное описание скрываются только на этих компактных мобильных экранах;
- hero высотой около 150 px: короткий kicker, заголовок и одна основная кнопка;
- вторичная кнопка «Мои проекты» на мобильном скрыта, потому что переход уже есть в нижней навигации;
- четыре существующих показателя показываются сеткой 2×2 без поясняющих строк;
- секция недавних проектов начинается на первом экране или сразу после небольшого скролла;
- карточки недавних проектов на мобильном становятся горизонтальными: компактная обложка, статус, название, количество AR-фото и дата.

### Desktop

Desktop-композиция и четыре показателя сохраняются. Hero может оставаться крупнее и показывать обе кнопки.

## Проекты

### Панель управления

- поиск и сортировка находятся в одной строке;
- сортировка на мобильном представлена компактной кнопкой с нативным select;
- статусы доступны одной строкой: «Все», «Черновики», «Активные», «Архив»;
- корзина и сброс — компактные кнопки с доступными aria-label;
- выбранный фильтр явно выделяется;
- параметры продолжают храниться в URL (`search`, `status`, `sort`, `page`).

### Карточки

- на мобильном карточки квадратные и располагаются по две в строке;
- фоном служит обложка проекта, а при её отсутствии — фотография-маркер из последней AR-работы проекта;
- поверх нижнего градиента видны только название проекта и количество AR-работ;
- статус, категория, описание, количество групп и дата на мобильной карточке скрыты;
- вся карточка открывает список AR-работ проекта;
- в правом верхнем углу находится меню из трёх точек с действиями «Редактировать», «Архивировать» и «Удалить»;
- каждое действие сохраняет подробный `aria-label` с названием проекта;
- черновики не скрываются и открываются тем же маршрутом проекта.

## Общие ограничения

- нижняя навигация не перекрывает основные действия;
- ширина документа не превышает ширину viewport;
- минимальная интерактивная область — 40–44 px;
- важные security/status eyebrow на других страницах не скрываются;
- мутации, схема базы и RLS-контракты не меняются; запасное превью читается из уже доступного приватного marker asset через короткоживущую signed URL;
- состояние загрузки и пустые состояния используют ту же компактную вертикальную ритмику.

## Приёмка

- 364×628: на Главной видны hero, показатели и начало «Недавних проектов»;
- 364×628: в Проектах видны поиск, строка фильтров и две квадратные карточки в одной строке;
- 319×628: нет горизонтального переполнения;
- меню каждой карточки содержит редактирование, архивирование и удаление;
- фильтры «Черновики», «Активные», «Архив», «Корзина» изменяют URL и список;
- создание, редактирование, архивирование, удаление и восстановление проектов продолжают работать;
- desktop, Android Chromium и iPhone WebKit проходят автоматические проверки.
