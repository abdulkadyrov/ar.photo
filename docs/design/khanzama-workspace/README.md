# Каталог постраничных макетов KHANZAMA

Открыть `index.html` — каталог листов с поиском и фильтрами по ролям. Каждый PNG
содержит одну страницу, ПК слева и телефон справа. Всего в плане 46 листов:
16 для администратора платформы, 20 для своего кабинета/CRM, 10 для входа и AR.

- `ROLES.md` — уточнение ролей по запросу владельца.
- `PAGE_REVIEW.md` — последовательный проход страниц и правила поведения.
- `SPEC.md` — ТЗ и этапы реализации.
- `pages.json` — названия, назначение и готовность каждого отдельного листа.
- `pages/` — сами PNG, разделённые на admin/account/access.
- `concept.png` — первая общая концепция; отдельные листы уточняют её.

Генеративные изображения — проектные макеты с демонстрационными данными. Любые
случайные подписи/числа внутри картинки не переопределяют роли и функциональные
правила. Ни новые экраны, ни новые разрешения не публикуются этим каталогом.

При добавлении листов `register_mockup.py ID SOURCE` сохраняет оригинал и
обновляет каталог. Для пересборки индекса: `python3 build_gallery.py`.
Для локального просмотра:

```sh
python3 -m http.server 8766 --bind 127.0.0.1 --directory docs/design/khanzama-workspace
```
